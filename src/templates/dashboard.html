Comment lire ces résultats ?

Les filtres mettent à jour les indicateurs, les deux graphiques et le tableau. Le rappel est la proportion des départs réels repérés ; la précision est la proportion d'alertes correspondant à un départ. Un indicateur sans dénominateur est indiqué « Non calculable ».

Les sous-groupes sont parfois petits : leurs résultats peuvent varier fortement. Une association ne prouve pas une cause. Le modèle est entraîné sur 5 634 autres clients ; aucun client de cette page n'a servi à cet entraînement.

Les fichiers sources, les tests et les limites sont inclus dans le rendu. Ce dashboard autonome fonctionne hors connexion et ne transmet aucune donnée.
